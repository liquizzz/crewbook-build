description: Where the project stands, from live GitHub and git state, with each session and its model, in a few lines. "/cb-progress report" adds the weekly measures and saves a dated report.
argument-hint: [report]
---

Report where this project stands: **$ARGUMENTS**. Read only what you need and check live state; do not repeat an earlier report. It works in any session, also before setup.

1. Read `.claude/project.json` (roles, setup), the Stage line and the Open decisions of `CLAUDE.md`. If `"setup": false`, say first: "Setup is not done: open "<Project> - Lead" and type /cb-setup. Every other step waits for it."
2. Check: `gh issue list --state open --limit 30` (`--label cr` for CRs waiting for the client's approval, `--label defect`), the open milestone and its progress, `gh pr list`, `gh run list --limit 3`, the last tag (`git describe --tags --abbrev=0`).
3. Reply in at most 10 lines, each issue and PR as a link with its short title (rule "Links" in `CLAUDE.md`): stage and the next approval (the plan, the milestone, the release) · open decisions and the step that needs each · done since the last tag · in progress (issue, session) · blocked or waiting for the owner or the client (CRs without the client's approval) · stalled sessions (rule "Stalled sessions": a started task with no commit, comment or message for 2 hours, or an idle session with an open task; a usage limit with its reset time) · the sessions: each role, idle or working, its task and model (`node scripts/model.mjs`) · the automation (`node scripts/crew-settings.mjs status`) · CI state · the one next step, as a hand-off block (format in `CLAUDE.md`) when it is in another session.
4. Change nothing, unless the argument is `report`: then, in the Lead, also run `node scripts/usage.mjs --days 7` (rule "Measuring") and add its tables and three lines on what they say (the rows of the model table that cost the most, the levels with the most fix rounds or moves up, the defects and where they came from, and one change worth trying), save it all as `docs/reports/<YYYY-MM-DD>.md` (template `docs/templates/daily-report.md`, with the decisions you need from the owner), push your branch and give the link. In another session, say that the Lead saves reports.
